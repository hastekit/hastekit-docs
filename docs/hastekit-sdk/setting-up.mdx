## Prerequisites

Use Go **1.25.3 or later**, matching the SDK's `go.mod`, and an API key for the provider you want to call. This example uses OpenAI directly and requires no gateway, Redis, or workflow service.

## Install

Create an application module, then add the SDK:

```sh
mkdir my-agent
cd my-agent
go mod init example.com/my-agent
go get github.com/hastekit/agent-sdk-go
```

Commit `go.mod` and `go.sum` to pin the resolved dependencies. Use `go get github.com/hastekit/agent-sdk-go@<version>` when upgrading to a specific release.

Set `OPENAI_API_KEY` in your environment. Do not put the key in source control.

## Create an agent

Save this as `main.go`:

```go
package main

import (
	"context"
	"fmt"
	hastekit "github.com/hastekit/agent-sdk-go"
	"log"
	"os"
)

func main() {
	client := hastekit.NewLLMClient([]hastekit.ProviderConfig{
		{
			ProviderName: hastekit.ProviderOpenAI,
			ApiKeys: []*hastekit.APIKeyConfig{
				{
					Name:   "primary",
					APIKey: os.Getenv("OPENAI_API_KEY"),
				},
			},
		},
	})

	model := client.Model("OpenAI/gpt-4.1-mini")

	agent, err := hastekit.NewAgent(&hastekit.AgentConfig{
		Name: "Assistant", LLM: model, Instruction: hastekit.NewPrompt("You are a helpful assistant."),
	})
	if err != nil {
		log.Fatal(err)
	}
	result, err := agent.Run(context.Background(), &hastekit.Input{
		Message: hastekit.UserTurn("Hello!"),
	})
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println(result.Text())
}
```

Run it with `go run .`.

`NewLLMClient` holds provider configuration. `Model("OpenAI/gpt-4.1-mini")` binds the provider and model for subsequent requests. `NewAgent` validates the agent configuration and returns an error on invalid setup. `Run` waits for completion; `Text()` extracts assistant text from the result.

The agent uses in-memory history and a process-local stream broker by default. Those defaults are useful for a first run, but do not provide persistence across restarts or communication between replicas.
