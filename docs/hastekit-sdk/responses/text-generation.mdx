---
title: "Text generation and streaming"
description: "Call a model directly and handle complete and streamed responses."
---

Use direct model calls when your application owns conversation state and tool execution. Use an [agent](/hastekit-sdk/agents/simple-agent) when the SDK should manage the model/tool loop.

The snippets assume `ctx` and a configured `model`. Import `pkg/gateway/llm/responses` and `pkg/utils`.

## Request a complete response

```go
response, err := model.NewResponses(ctx, &responses.Request{
    Instructions: utils.Ptr("Answer concisely."),
    Input: responses.InputUnion{OfString: utils.Ptr("Explain a Go interface.")},
    Parameters: responses.Parameters{MaxOutputTokens: utils.Ptr(300)},
})
if err != nil { return err }
if response.Error != nil { return fmt.Errorf("model response: %s", response.Error.Message) }
for _, item := range response.Output {
    if item.OfOutputMessage == nil || item.OfOutputMessage.Content == nil { continue }
    for _, part := range *item.OfOutputMessage.Content {
        if part.OfOutputText != nil { fmt.Print(part.OfOutputText.Text) }
    }
}
```

## Streaming responses

```go
streamCtx, cancel := context.WithCancel(ctx)
defer cancel()
stream, err := model.NewStreamingResponses(streamCtx, &responses.Request{
    Input: responses.InputUnion{OfString: utils.Ptr("Explain a Go interface.")},
})
if err != nil { return err }
for chunk := range stream {
    if chunk.OfError != nil { return chunk.OfError }
    if chunk.OfOutputTextDelta != nil { fmt.Print(chunk.OfOutputTextDelta.Delta) }
}
if err := streamCtx.Err(); err != nil { return err }
```

Cancel the stream context when you stop consuming, so producer work can unwind. Account for terminal events if your application needs to distinguish completed output from an incomplete response. Do not silently discard in-band errors.

## Continue a conversation

For direct model calls, retain the input and output items yourself. Convert returned output items with `item.AsInput()` and append the next user message to `responses.InputMessageList`. Preserve reasoning and tool-call items required by the provider, not just visible assistant text.

The bound client does not maintain a thread for you. For persisted conversation state, use [agent history](/hastekit-sdk/agents/conversations/history).
