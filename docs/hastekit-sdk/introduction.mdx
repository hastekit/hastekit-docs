HasteKit is a Go SDK for agents that use tools, keep conversation history, delegate work, and pause for human input. Run an agent in your application, expose it through a chat interface, or move its execution to Temporal or Restate.

The Go module is `github.com/hastekit/agent-sdk-go`. These guides import the root package as `hastekit`. You can call providers directly; a separately deployed HasteKit Gateway is optional.

## Build your first agent

After [installing the SDK and configuring a provider](/hastekit-sdk/setting-up), create an agent and send a turn. Here `model` is the provider returned by `client.Model(...)`, and `ctx` is your request context:

```go
agent, err := hastekit.NewAgent(&hastekit.AgentConfig{
    Name: "assistant",
    LLM: model,
    Instruction: hastekit.NewPrompt("Give clear, concise answers."),
})
if err != nil { return err }
result, err := agent.Run(ctx, &hastekit.Input{
    ThreadID: "first-conversation",
    Message: hastekit.UserTurn("What can you help me with?"),
})
if err != nil { return err }
fmt.Println(result.Text())
```

Add function tools when the agent needs to act, and reuse a thread ID when it needs earlier turns. [Agents and execution](/hastekit-sdk/agents/simple-agent) explains streaming, cancellation, and paused results.

## Learn the core concepts

Start with [prompts and run context](/hastekit-sdk/agents/system-instruction), [structured output](/hastekit-sdk/responses/structured-output), and [conversation history](/hastekit-sdk/agents/conversations/history). Add [middleware](/hastekit-sdk/agents/hooks) to customize execution and [evaluations](/hastekit-sdk/testing) to measure changes to models, instructions, and tools.

These guides follow the current SDK APIs. Pin your module version and use matching documentation when upgrading. Complete programs include imports; shorter snippets name their prerequisites. Model IDs are examples—choose a model available to your account with the capabilities your application needs.
